# PoolTrack

Test • Track • Swim

PoolTrack is a cross-platform mobile app built with .NET MAUI to track pool chemical tests and manage pool maintenance.

## Features

- Record pool chemical tests
- Track chemical history
- Multiple pool support
- Chemical dosing recommendations
- Charts and analytics

## Tech Stack

.NET MAUI
SQLite
MVVM
Microcharts
